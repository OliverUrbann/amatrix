# Icon templates

`Drawer.info` and `Plate.info` are MagicWB icons by Martin Huttenloher,
`Guide.info` is by Mario Cattaneo (their credit is in the tool types and is
kept in the icons built from them).  `make-icon.py` draws the small Amatrix
logo into them.  They are not covered by the MIT licence of Amatrix.
