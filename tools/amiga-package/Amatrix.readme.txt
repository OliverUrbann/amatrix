=== English ===

Amatrix is a native Matrix client for classic AmigaOS, written in C for
the 68020 and better.  It talks to a Matrix server directly: no bridge,
no proxy.  Matrix is an open protocol for chat (matrix.org); Amatrix
connects to the Matrix network and chats with Element, FluffyChat and the
other clients.  The user interface is MUI: a list of chats and rooms with
pictures on the left, one chat window per room.

Features

- End-to-end encryption (Olm/Megolm) in both directions, key backup and
  security key, so that encrypted history is readable (libolm, ported)
- Direct chats, rooms, spaces, invitations, room settings, members with
  roles, remove/ban, knocking, room upgrades
- Replies, edits, deletes, threads, reactions, pinned messages, polls,
  formatted messages (bold, italic, lists, code), Markdown while typing
- Pictures, files, voice messages: previews in the chat, send with the file
  requester or by dropping Workbench icons into the window
- Link previews, locations, emojis as small pictures, typing notices and
  read receipts ("read by ...")
- Search in all rooms, export a chat as text or HTML, drafts, history kept
  locally and shown at once at start
- Notifications through Herald, AppIcon with unread marker when iconified
- Password for the stored data (AES-256), several sessions, own profile
- Full ARexx port (AMATRIX.1)
- Languages (locale.library catalogs): English (built in), Deutsch,
  Francais, Espanol, Italiano, Nederlands, Svenska.  Amatrix follows the
  Locale preferences; the tool type or argument LANGUAGE=english (or
  deutsch, ...) forces one.  The translations other than German and
  English are machine-assisted and not yet reviewed by native speakers.
  A new language needs only a translation file (see the source).

Requirements
- 68020 or better
- MUI 5 (muimaster.library V20) with NList.mcc and BetterString.mcc
  (both are in the MUI 5 "contrib" package)
- AmiSSL 5 and a running TCP/IP stack (Roadshow, AmiTCP, ...)
- Optional: Herald (Aminet util/cdity/Herald) for notifications,
  openurl.library to open links, opusdec for voice messages

An account to log in with
You need a Matrix account with a user name and a PASSWORD on a server that
allows password logins (matrix.org does).  Accounts that only work
through single sign-on ("Continue with Google/GitHub/...") or the newer
browser login cannot log in.  If your account has no password yet, set
one in Element first (Settings > Account > Change password).

Installation
Copy the drawer "Amatrix" wherever you like and double click "Amatrix".
Program, icon and language catalogs are all inside the drawer.

Documentation
Amatrix.guide (AmigaGuide, open it with MultiView) is the manual: first
start (login, password for the stored data, verifying the device with the
security key), every menu and button, all functions and the complete ARexx
reference.  It is in the drawer; Amatrix.de.guide is the German version.

Known bugs
- Thin horizontal lines sometimes appear in picture previews, mostly
  while scrolling (NList does not draw the bottom row of a strip now and
  then).
- MorphOS (reported, possibly MorphOS-specific, since Amatrix has been
  tested only with MUI 5 on OS 3 so far): the room list in the main
  window shows its entries without any text; the space choice above it
  shows the last space twice and leaves out another one.

=== Deutsch ===

Amatrix ist ein nativer Matrix-Client fuer das klassische AmigaOS, in C
fuer 68020 und besser geschrieben.  Er spricht direkt mit dem Matrix-
Server: keine Bruecke, kein Proxy.  Matrix ist ein offenes Chat-Protokoll
(matrix.org); Amatrix verbindet sich mit dem Matrix-Netzwerk und chattet
mit Element, FluffyChat und den anderen Clients.  Die Oberflaeche ist MUI:
links die Liste der Chats und Raeume mit Bildern, pro Raum ein Chatfenster.

Merkmale

- Ende-zu-Ende-Verschluesselung (Olm/Megolm) in beide Richtungen,
  Schluessel-Backup und Sicherheitsschluessel, damit verschluesselter Verlauf
  lesbar ist (libolm, portiert)
- Direktchats, Raeume, Spaces, Einladungen, Raum-Einstellungen, Mitglieder
  mit Rollen, Entfernen/Sperren, Anklopfen, Raum-Upgrades
- Antworten, Bearbeiten, Loeschen, Threads, Reaktionen, angeheftete
  Nachrichten, Umfragen, formatierte Nachrichten (fett, kursiv, Listen,
  Code), Markdown beim Tippen
- Bilder, Dateien, Sprachnachrichten: Vorschau im Chat, Senden mit dem
  Dateirequester oder per Drag-and-drop von Workbench-Icons ins Fenster
- Link-Vorschauen, Standorte, Emojis als kleine Bilder, Tippanzeige und
  Lesebestaetigungen ("gelesen von ...")
- Suche in allen Raeumen, Chat als Text oder HTML exportieren, Entwuerfe,
  Verlauf lokal gespeichert und beim Start sofort sichtbar
- Benachrichtigungen ueber Herald, AppIcon mit Ungelesen-Markierung beim
  Ikonifizieren
- Passwort fuer die gespeicherten Daten (AES-256), mehrere Sitzungen,
  eigenes Profil
- Vollstaendiger ARexx-Port (AMATRIX.1)
- Sprachen (locale.library-Kataloge): Englisch (eingebaut), Deutsch,
  Francais, Espanol, Italiano, Nederlands, Svenska.  Amatrix folgt den
  Locale-Einstellungen; der Tooltype bzw. das Argument LANGUAGE=english
  (oder deutsch, ...) erzwingt eine.  Die Uebersetzungen ausser Deutsch und
  Englisch sind maschinell unterstuetzt und noch nicht von Muttersprachlern
  geprueft.  Eine neue Sprache braucht nur eine Uebersetzungsdatei (siehe
  Quellcode).

Voraussetzungen
- 68020 oder besser
- MUI 5 (muimaster.library V20) mit NList.mcc und BetterString.mcc
  (beide im MUI-5-Paket "contrib" enthalten)
- AmiSSL 5 und ein laufender TCP/IP-Stack (Roadshow, AmiTCP, ...)
- Optional: Herald (Aminet util/cdity/Herald) fuer Benachrichtigungen,
  openurl.library zum Oeffnen von Links, opusdec fuer Sprachnachrichten

Ein Konto zum Anmelden
Noetig ist ein Matrix-Konto mit Benutzername und PASSWORT auf einem Server,
der Passwort-Anmeldung erlaubt (matrix.org tut das).  Konten, die nur ueber
Single Sign-on ("Weiter mit Google/GitHub/...") oder die neuere Browser-
Anmeldung funktionieren, koennen sich nicht anmelden.  Hat dein Konto noch
kein Passwort, vergib zuerst in Element eines (Einstellungen > Konto >
Passwort aendern).

Installation
Die Schublade "Amatrix" an einen beliebigen Ort kopieren und "Amatrix"
doppelklicken.  Programm, Icon und Sprachkataloge liegen alle darin.

Dokumentation
Amatrix.de.guide (AmigaGuide, mit MultiView oeffnen) ist das Handbuch:
erster Start (Anmeldung, Passwort fuer die gespeicherten Daten, Geraet mit
dem Sicherheitsschluessel verifizieren), jedes Menue und jeder Knopf, alle
Funktionen und die vollstaendige ARexx-Referenz (englisch).  Es liegt in
der Schublade; Amatrix.guide ist die englische Fassung.

Bekannte Fehler
- In Bildvorschauen erscheinen manchmal duenne waagerechte Linien, meist
  beim Scrollen (NList zeichnet die unterste Zeile eines Streifens hin und
  wieder nicht).
- MorphOS (gemeldet, moeglicherweise MorphOS-spezifisch, da Amatrix
  bisher nur mit MUI 5 unter OS 3 getestet ist): Die Raumliste im
  Hauptfenster zeigt ihre Eintraege ohne Text; die Space-Auswahl darueber
  zeigt den letzten Space doppelt und laesst einen anderen weg.
